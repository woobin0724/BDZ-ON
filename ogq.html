앱 화면 캡처 [입력 필요] Streamlit 4탭 화면 또는 매칭 점수 대시보드 캡처를 넣어 주세요.
  1. 01 문제
    마이스터고 학생에게 맞춘 취업 컨설팅이 필요했습니다

    마이스터고 학생 맞춤 취업 컨설팅과 커리어 로드맵을 목표로 했습니다. 구체적인 문제 상황 [입력 필요]

  2. 02 해결
    Streamlit 4탭 웹앱과 매칭 점수 대시보드

    학생 정보를 100점 만점으로 정량 매칭하고, 결과를 대시보드로 보여 주는 웹앱을 만들었습니다.

  3. 03 핵심 기능
    100점 정량 매칭 로직
    30 40 20 10
    내신 30자격증 40 전공적합성 20인재상 10
    API 이중화

    Q-Net·고용24·잡알리오 공식 API를 연동하고, 장애에 대비해 Fallback JSON을 두었습니다.

    캐싱으로 비용 방어

    st.cache_data 캐싱으로 반복 호출을 줄여 API 과금을 막았습니다.

    Claude API 자소서 생성

    Claude API로 자기소개서 생성을 자동화했습니다.
